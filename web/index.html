How the repo works

  • One folder per project; inside: docs/, models/, web/ and one folder per assignment part.
  • Every prompt gets a log entry: in the project it worked on, or in the general log.
  • Code and docs in English; every page runs the project's real code.
  • Every push to main is tested and deployed by GitHub Actions.
