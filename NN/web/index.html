BCD Decoder Net 4 → 16 → 7

A feedforward neural network written from scratch that turns a 4-bit BCD digit (0–9) into the seven segments A–G of a display. It is built in six parts: Python, a TensorFlow comparison, C inference, and an ESP32. Every page runs the real code of its part in your browser. Nothing is precomputed, except where a page says so.

The pipeline

digit 5→BCD 0101→4 inputs→ 16 hidden (sigmoid)→7 outputs→≥ 0.5 → A-CD-FG→GPIO pins

Network from scratch

Neuron → Layer → NeuralNetwork with backpropagation, trained on XOR (2-2-1) and the 7-segment decoder (4-16-7), exported as JSON, TXT and C header. You can retrain it right in the page.
