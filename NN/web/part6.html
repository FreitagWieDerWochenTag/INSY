Part 6 · ESP32 + 7-segment display

The Arduino sketch reads a digit from the serial monitor, turns it into 4 BCD bits, runs the C network from Part 5 and switches 7 GPIOs. Here the unchanged sketch runs as WebAssembly against a small mock of the Arduino API (). The board below shows the pin levels the sketch set with digitalWrite(), wired as in the assignment's table (each through 330 Ω).
